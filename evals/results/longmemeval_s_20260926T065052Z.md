# LongMemEval (S variant) on Vertex AI Memory Bank: 10-question pilot, run 1c6ded (2026-09-26)

## What this is

[LongMemEval](https://github.com/xiaowu0162/LongMemEval) (Wu et al., ICLR 2025; data `xiaowu0162/longmemeval-cleaned`, MIT)
is a public benchmark for chat-assistant memory: 500 questions, each with its own history of dated user-assistant
conversations. In the **S** variant each history has ~40-53 conversations (~115-125K tokens), of which 1-4 hold the
answer. Question types: single-session-user, single-session-assistant, single-session-preference, multi-session,
temporal-reasoning, knowledge-update, plus abstention (questions about things that never happened).

It is the only benchmark with a public number for Memory Bank: Redis's report (2026-09-21,
https://redis.io/resources/agent-memory-benchmark-report/) reproduced **42.4%** on all 500 S questions (GPT-4o answer and
judge), against ~70% in the RMM research paper Google cites. That is a competitor's report.

## Setup

- **Questions:** 10, stratified by type (2 temporal, 2 multi-session, 2 knowledge-update, 1 each of the single-session
  types, 1 abstention), `random.Random(7)` over the question ids. The same 10 were run on the oracle variant first
  (`longmemeval_oracle_20260926T052527Z.md`).
- **Engine:** `jpmc-ccb-eval-lme` (LME_ENGINE_ID 8531677518158102528), created for this with Memory Bank **defaults**:
  managed topics only, service-default generation model (gemini-3.5-flash per the docs for engines created after
  2026-06-29), text-embedding-005.
- **Writes:** one scope per question; one `memories:generate` call per conversation (directContentsSource, user and model
  turns, **consolidation on**), in date order; the conversation date prefixed to its first turn, because events carry no
  timestamp.
- **Answer conditions** (gemini-2.5-flash, one neutral prompt that gives the question date):
  - `mb_top8`: the 8 memories returned by similarity search on the question. This is how the app reads.
  - `mb_all`: every memory in the scope. There is no search, so this shows what extraction kept.
  - `full`: the raw conversations. This is the ceiling.
- **Grading:** LongMemEval's own yes/no judge prompts (`evaluate_qa.py`), judged by **gemini-2.5-pro instead of GPT-4o**.
  Results are comparable with each other, and only roughly with published numbers.

With n=10, 5/10 is consistent with roughly 25-75%. The failure types are the finding, not the score.

## Why answers failed (S run)

| Question | Cause |
|---|---|
| 70b3e69b single-session-assistant ("the singer you mentioned") | **Never stored.** Nothing the assistant said became a memory, in both oracle and S. |
| 1a8a66a6 multi-session ("how many magazine subscriptions") | **Reworded away.** "I subscribe to Architectural Digest" became "I love Architectural Digest", so the answer counted 1 instead of 2. |
| gpt4_93f6379c temporal ("which group did I join first") | **Date dropped.** Page Turners kept only "May 2023", so the order was unknown. |
| 88432d0a multi-session ("how many times did I bake in two weeks") | **Dates dropped.** Only 1 of 4 bakes kept its date. `full` also failed (it counted 6), so this is a hard question. |
| 4dfccbf8 temporal ("what did I do with Rachel") | **Search missed it.** The ukulele memory exists (`mb_all` was correct), but the top-8 returned a note about a different Rachel. |

Correct in all conditions: a single fact (20 Spotify playlists), a preference (coffee creamer), a knowledge update (10-12
hours on the sculpture), and the abstention question. The Paris vs Hawaii trip question was wrong in oracle and right
here, because the Hawaii memory was worded without "recently" this time. Memory wording varies between runs.

These are the same weaknesses we saw on the banking conversations (Experiment 3 and the attribution audit): facts the
agent told the customer are not stored, and dates and one-off details are dropped.

## Time and cost

- 478 conversations written in 70 min with 2 writers, ~17.5 s per conversation, ~800 s per question, ~55 memories per question.
- Our model spend was about $1 (answers, including 10 full-context calls at ~125K tokens, plus 30 judge calls).
  Memory Bank's own charges are not included.
